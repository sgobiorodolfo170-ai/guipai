# Review页面使用说明

## 概述

Review页面是TradeInsight项目中的股票复盘分析页面，主要用于展示当日股票市场的涨停池数据、行业板块表现和市场统计信息。

## 功能特性

### 1. 数据概览区
- **上证指数**: 显示上证指数当前价格和涨跌幅
- **涨停统计**: 显示当日涨停股票数量和成功率
- **跌停统计**: 显示当日跌停股票数量
- **连板分析**: 显示一进二、二进三等连板转换数据
- **高标股**: 显示当日最高连板数的股票

### 2. 涨停池分析
左侧主要区域展示涨停股票的分类信息：
- **高位板**: 5连板及以上的股票
- **四连板**: 4连板股票
- **三连板**: 3连板股票  
- **二连板**: 2连板股票
- **一连板**: 1连板股票

每个股票卡片显示：
- 连板级别
- 股票名称和代码
- 涨跌幅
- 所属行业
- 涨停统计
- 成交额和换手率

### 3. 行业板块排行
右侧上方显示当日表现最好的10个行业板块：
- 行业名称
- 涨跌幅
- 领涨股票

### 4. 市场统计
右侧下方显示整体市场统计：
- 上涨家数
- 下跌家数
- 平盘家数
- 总成交额

## API接口

页面使用以下AKTOOLS API接口获取数据：

1. **获取涨停池**: `/api/aktools/stock/limit`
2. **获取跌停池**: `/api/aktools/stock/drop`
3. **获取行业板块**: `/api/aktools/stock/industry`
4. **获取实时行情**: `/api/aktools/stock/spot`

## 技术实现

### 文件结构
```
src/
├── views/review/Review.vue          # 主页面组件
├── services/aktools.service.js      # AKTOOLS API服务
├── composables/useReview.js         # Review页面逻辑复用
```

### 主要技术栈
- **Vue 3**: 使用Composition API
- **Element Plus**: UI组件库
- **Axios**: HTTP请求库
- **Vue Router**: 路由管理

### 数据流程
1. 页面加载时并行请求所有API接口
2. 使用composable管理数据状态和业务逻辑
3. 响应式更新UI显示

## 使用方法

### 1. 启动后端服务
确保AKTOOLS API服务正常运行在 `http://localhost:8080`

### 2. 配置环境变量
在`.env`文件中配置API基础URL：
```
VITE_API_BASE_URL=http://localhost:8080
```

### 3. 访问页面
在浏览器中访问 `/review` 路径即可查看复盘页面

### 4. 测试API
可以访问 `/test` 页面测试AKTOOLS API接口是否正常工作

## 注意事项

1. **日期格式**: API接口使用 `yyyyMMdd` 格式的日期参数
2. **数据更新**: 页面数据基于当日实时数据，需要在交易时间内获取最新信息
3. **错误处理**: 页面包含完整的错误处理和加载状态显示
4. **响应式设计**: 页面支持不同屏幕尺寸的响应式布局
