# Review页面使用说明

## 概述

Review页面（复盘页）是龟派桌面应用中的股票复盘分析页面，展示当日涨停池/跌停池数据、三大指数概览、最高连板等核心指标，支持按市场（主板/科创板/创业板）和时段（今日/昨日表现）筛选查看。

## 功能特性

### 1. 数据概览区（第一行卡片）
- **上证指数**: 显示上证指数当前价格和涨跌幅
- **深证指数**: 显示深证成指当前价格和涨跌幅
- **创业板指数**: 显示创业板指当前价格和涨跌幅
- **最高板**: 显示当日最高连板数

> 指数数据来自 AKTools 指数实时行情接口，合并上证系列指数 + 深证系列指数后按代码提取（000001 / 399001 / 399006）。

### 2. 涨停池分析
左侧主要区域展示涨停股票的分类信息：
- **高位板**: 5连板及以上的股票
- **四连板**: 4连板股票
- **三连板**: 3连板股票
- **二连板**: 2连板股票
- **一连板**: 1连板股票

每个股票卡片显示：
- 连板级别
- 股票名称和代码
- 涨跌幅（今日或昨日表现）
- 所属行业
- 涨停统计
- 成交额和换手率
- 可点击展开迷你 K 线图

### 3. 市场/时段筛选
- 市场筛选：全部市场 / 主板 / 科创板 / 创业板
- 时段筛选：今日数据 / 昨日表现

### 4. 详细指标网格（点击查看 30 天历史）
- 涨停股 / 跌停股 数量
- 一字板数量
- 连板率
- 炸板回封数
- 最高连板
- 昨日涨停涨幅
- 均支持点击弹出历史趋势弹窗

## 缓存机制（重要）

复盘页采用**前端本地缓存持久化**设计：

- 打开页面时**优先读取 localStorage 缓存**（`utils/cacheStorage.js`），直接展示上次数据，**不主动拉取实时数据**
- 点击右上角**刷新按钮**才从后端拉取最新数据，并写入本地缓存
- 首次打开（无缓存）时会自动拉取一次
- 缓存的交易日随数据一同保存，标题栏日期取自缓存交易日

## API接口

页面经内嵌后端（Electron 主进程 Express，默认 `http://localhost:8080`）调用以下 AKTOOLS 接口：

1. **获取涨停池**: `/api/aktools/stock/limit?date=yyyyMMdd`
2. **获取跌停池**: `/api/aktools/stock/drop?date=yyyyMMdd`
3. **昨日涨停池**: `/api/aktools/stock/ztPoolPrevious?date=yyyyMMdd`
4. **指数行情**: `/api/aktools/stock/indexSpot?symbol=上证系列指数|深证系列指数`
5. **个股K线**: `/api/aktools/stock/history`（展开迷你K线时按需加载）
6. **涨跌停统计历史**: `/api/limit-board-statistics/*`（历史弹窗）

## 技术实现

### 文件结构
```
src/
├── views/review/Review.vue          # 主页面组件
├── services/aktools.service.js      # AKTOOLS API服务
├── composables/useReview.js         # Review页面逻辑复用（含缓存读写）
├── utils/cacheStorage.js            # 本地缓存工具
└── components/common/HistoryDataModal.vue  # 历史数据弹窗
```

### 主要技术栈
- **Vue 3**: Composition API（`<script setup>`）
- **Element Plus**: UI组件库
- **ECharts**: K线图、历史趋势图
- **Axios**: HTTP请求库
- **Vue Router**: 路由管理

### 数据流程
1. 页面挂载时先读本地缓存（命中则直出，不请求网络）
2. 缓存未命中才并行请求各 API 接口并写入缓存
3. 刷新按钮强制拉取最新数据并更新缓存
4. composable 统一管理数据状态与业务逻辑，响应式更新 UI

## 使用方法

### 1. 启动应用
在仓库根目录执行 `npm run dev`，Electron 桌面窗口打开后点击侧边栏「复盘」。

### 2. 查看数据
打开页面即展示上次缓存的复盘数据；点击右上角刷新按钮获取最新数据。

### 3. 查看历史趋势
点击「涨停股」「跌停股」「一字板数量」等指标卡片，弹出最近 30 天历史趋势弹窗。

## 注意事项

1. **日期格式**: API接口使用 `yyyyMMdd` 格式的日期参数
2. **数据更新**: 页面默认展示缓存数据，交易时段内请点击刷新按钮获取最新信息
3. **缓存清除**: 缓存存于应用 localStorage，可在「设置/数据管理」中清理
4. **错误处理**: 页面包含完整的错误处理和加载状态显示
